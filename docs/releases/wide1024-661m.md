# Wide1024 661M release provenance

The [game archive](../../arena_archive_played_games/games.json) records the exact executable and weights used for the 144 published games.

## Match executable

The Windows match bundle is `pollock-wide1024-661m-windows-x64.zip`. From the extracted bundle, calculate these file hashes and compare them with `candidate.executable_sha256` and `candidate.weights_sha256` in the game archive.

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\pollock.exe, .\played\wide1024-661m.pnn
```

The measured source commit is `bd70aa743bb19787ef173f72c46ab631774069cb`. The build files and source imported in [PR #8](https://github.com/MecGlandorff/pollock/pull/8) match the following Git objects from that commit. From a source checkout, run `git rev-parse HEAD:build.zig HEAD:build.zig.zon HEAD:src` to check them in order.

| `build.zig` | `25d13ae268f9d22db71c30aeba3870b0596458ed` |
| `build.zig.zon` | `f04d7e777381be9d48af72ba81a7ae73de53e408` |

The match build used Windows x64 Zig 0.17.1 in ReleaseFast mode with the host's native CPU target. The archive records the Zig executable hash under `candidate.compiler_sha256`.

```powershell
zig build -j1 -Doptimize=ReleaseFast
```

In a local rebuild, the Windows executable differed from the match executable by 20 bytes. Four were in the COFF timestamp and 16 were in `.buildid`. The executable code and data sections matched byte for byte. Use the archived match executable hash to identify the file that played.

## Training record

The original run's setup records random initialization with seed `34001024` using PyTorch `2.11.0+cu126` on an RTX 4060 Laptop GPU. The initial tensor hash covers the parameter names and their raw contiguous tensor bytes in model order. The 661M continuation resumed the 631,575,320-position checkpoint and processed 30,108,925 more positions. The release averaged the model parameters from checkpoints `2392064`, `2457600`, `2467383`, `2519363`, and `2585009` before exporting the `.pnn`. Its hash is `candidate.weights_sha256` in the game archive.
